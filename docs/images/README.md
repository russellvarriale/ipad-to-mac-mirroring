# Documentation image provenance

These window-only screenshots were captured on 2026-10-26 from an isolated
screenshot fixture of the real AppKit layout. Device discovery, receiver startup,
and capture permissions were disabled in that fixture. The video canvas uses
generated H.264 sample content visibly marked ILLUSTRATIVE SAMPLE SCREEN.

No personal iPad screen, device name, pairing code, desktop, or account content
is present. JPEG application/comment metadata is removed without changing pixel data. The
original UI/artwork is covered by the repository's scoped MIT license.
